# 实施

1. 固定 Codex 参考提交及机制映射；核对整个调用链与既有来源合同。
2. Java worker：原生工具消息 DTO、模型请求/响应、压缩模型方法及协议回归。
3. Python worker：删除 DB-GPT 循环，以原生调用/结果历史运行同一工具主线，迁移旧框架专用测试而保留业务负例。
4. Conversation worker：对话持久化、迁移、压缩检查点、任务生命周期与隔离测试。
5. Root：依赖闭包/发布脚本、前端接线、文档及端到端合成验证；必要时将前端子任务交空闲 worker。
6. 核对无旧框架生产调用方，运行相关 Java/Python/前端回归及真实 loopback 联调；如未运行生产或真实模型须明确登记。

旧实现源码/配置/仅框架身份测试本切移除；线上旧 release 只作为独立回滚制品保留，不修改它或用它覆盖新数据库。
