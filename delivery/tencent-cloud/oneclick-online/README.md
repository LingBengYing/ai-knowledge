# 知识库轻量在线启动包

本包不带镜像，只包含启动器和配置。Mac 解压后双击 `启动.command`；Linux 在解压目录执行 `./start.sh`。Docker 必须已启动，要求 Engine 28+、Compose v2；镜像为 Linux AMD64，Apple Silicon 需要 AMD64 模拟。建议 Docker 8GB 内存、20GB 可用空间。

首次自动从腾讯云拉取缺少的固定版本镜像，之后校验并复用本机缓存。首次下载仍约1GB（共享层、已有缓存会减少下载）；轻量包减少的是文件复制体积，不是服务运行所需的镜像体积。默认未启用的云OCR镜像不下载。

## 私有仓库登录

仓库保持私有。已登录且有权限就直接使用；未登录时，启动器会在终端引导输入一次仓库密码，不需要另写命令。默认账号为本项目腾讯云账号；如使用另一个有权限账号，首次运行时设置 `KB_REGISTRY_USER`。密码由 Docker 交互接收，交给当前用户的 Docker 凭据存储，启动器及压缩包不保存密码。缓存镜像齐全时连仓库登录都不会触发；凭据失效或被清除时可能需要重新登录。

网络、证书、磁盘或仓库不可用不会循环要求密码；失败保留已下载镜像，修复后再次运行即可。本包不自动公开仓库、不分发账号密码。

## 访问和数据

默认只允许安装机器本机访问 https://knowledge.localhost:18443/ 。首次自签证书提示需由本人处理，启动器不修改系统信任设置。模型密钥在网页“模型设置”配置一次；后续保存在本机数据卷。首次启动不自动调用云模型。局域网或公网部署需另配网络入口、证书和认证。

`停止.command` / `stop.sh` 停止服务但保留数据；`状态.command` / `status.sh` 查看健康情况。不要删除 Docker 数据卷。

容器布局：常驻的 `net` 容器（复用已固定的 api 镜像，只运行空等待循环）持有本机端口和共享回环网络；api、milvus、agent、web、gateway 都加入它。api 因内存不足自行退出并被 Docker 自动重启后，会重新加入同一网络，端口与内部连接不受影响。旧版本安装再次运行启动入口时，会先自动停止并移除旧容器（不删数据卷）再按新布局启动；若该步骤失败，先运行一次停止入口再启动即可。

### 已经用离线版安装的机器

无需重新安装，原版启动器仍可用。若要换为在线入口：先用旧目录的停止入口停止服务，再将旧目录的 `.env` 复制到新目录，保持连接相同数据卷，并只使用新目录的启动入口。不要让两个目录同时操作同一个项目。不要复制生产数据库作为安装默认内容。

新机器首次安装不需要复制任何 `.env`。本包不含资料、模型密钥、仓库密码或本机运行配置。

## 验证边界

运行编排与已经完成本机启动、TXT解析、向量Strong读回及重启持久化验证的离线版一致。在线版额外验证了缓存复用与下载流程控制。当前本机已缓存镜像，因此本轮没有重新登录仓库或在全新机器完整下载；远端镜像此前已上传并逐摘要核对。模型质量、公网部署、Windows双击入口不属于此包验收范围。
