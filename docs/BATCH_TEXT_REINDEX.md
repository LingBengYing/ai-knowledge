# 批量重建选中文本索引

当前状态：0041及前端0030已实现；2026-10-04 01:32:29 +08仅后端跳过全部测试编译运行包成功，未测试、部署或页面验收。正式范围见[正常操作契约](changes/0041-batch-text-reindex/spec.md)。

## 操作前

先在“模型配置”保存并应用文字模型配置。只有当前服务实际开放 `batch_text_reindex` 能力，且资料具有当前写权限、完整已发布材料和可重建资格时，页面才允许提交。

这项操作使用当前已应用的文字嵌入模型和索引目标，重新处理资料已经保存的完整解析材料。它不重新解析原文件，也不自动生成新的图片或音频向量；已有合格媒体向量沿原重建流程核对和复用。文字嵌入与索引写入可能产生服务商费用。

如果要更换文字嵌入模型、修订或维度，请使用模型配置中的“重建并应用”全库流程。批量重建选中资料不会应用未启用的模型草稿。

## 页面步骤

1. 打开资料列表，在当前页勾选需要重建的资料。
2. 点击“重建选中文本索引”。先查看本次合格资料，以及不具资格、不会提交的资料和数量。不会在不告知的情况下缩小选择范围。
3. 在确认框核对实际提交的资料和当前已保存的解析材料。若资格、发布版本、任务或登录身份发生变化，先刷新并重新确认。
4. 明确确认后提交。页面按资料分别显示“后台任务已创建”或失败原因。只有确认过的合格项会提交；失败及未提交项保留选择，问题、问答范围和整理草稿保持。
5. 从各资料行、详情及索引任务入口查看后台进度。每份资料独立完成；一项失败不会撤回其他已经创建的任务。

“任务已创建”只表示排队成功，不等于索引完成。处理期间旧发布继续可用；失败或取消也保留旧发布。完整新索引成功后，该资料才切换到新发布，其他资料按各自任务进度处理。切换后重新执行召回或问答以取得新版本来源，页面不会清空已有问题草稿。

## 失败或结果未知

看到逐项失败时，先按该项提示处理权限、活动任务或版本变化，再刷新资料状态。网络中断、超时或丢失响应时，部分任务可能已经创建：先刷新列表和任务，逐项核对结果，不要直接重复提交。页面不会自动重试或自动重发整个批次。

## 接口含义

本切沿用 `POST /v1/management/document-actions`，提交 `action=reindex`、1–100 个唯一 `document_ids`，以及与这些资料一一对应的 `base_publication_ids`。响应保持逐项 `items`；HTTP 200 不表示每项成功。成功项 `ok=true`、`receipt.status=queued` 只证明后台任务创建，失败项提供安全错误码与说明。最终发布状态仍以各资料索引任务为准。
