# 行为合同

- 21 种后缀不区分大小写；既有 PDF/TXT/MD 解析和身份保持，新格式实际解析，不能仅修改白名单或把二进制当 UTF-8。
- Office/ODT/EPUB/邮件使用成熟的本地解析器；结构化文本保留可读正文、表格和必要标题；HTML/XML/MDX 不执行脚本、外部资源或实体，邮件附件不递归作为正文证据。
- 新格式使用明确的解析文本位置，不宣称 Word 渲染页码、工作表单元格或 VTT 对应媒体已实现精确跳转；PDF 原有页码定位保持。
- 原件按实际 MIME 读取、校验 SHA，主动内容只下载，不在应用同源执行。解析结果经过既有不可变 ParsedText/分块/摄取协议；不修改旧资料，不需要新数据库迁移。
- 沿用单文件 20MiB（图片 10MiB）及解析进程边界；格式、损坏/加密、空正文和体积失败有可识别原因，不把失败存成成功。无自动重试、无云调用。
- 合成文件逐格式验证真实解析与持久上传/原件回读；用户 XLSX 仅本机私有校验，不进入 Git 或模型。解析成功不等于索引、模型质量或生产验收。
