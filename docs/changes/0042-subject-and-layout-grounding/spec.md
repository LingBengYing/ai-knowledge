字段值仍必须被模型提供的精确原文摘录完整覆盖。被采用的项目名称声明同时输出为原文引用依赖，保留真实 CP offset、来源与 SHA；名称依赖不能单独补足预算或日期覆盖。最终相同原引用范围合并事实身份，完整多事实覆盖与引用总限额继续保持。全部原上下文继续用于冲突及指令、条件、否定检查。

已知名称、预算、启动日期字段的标签单行紧接值单行可组成精确原 range。必须无空行、下一行不是另一字段标签或另一个赋值，模型原摘录须覆盖两行；原文换行及值不改写。英文冠词处理原来已经正常，不增加跨语言推断或任意字段同义词。
