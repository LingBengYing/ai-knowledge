# 原声向量合同

- AV-01：独立默认关闭rag.audio-embedding.enabled，仅development/test及字面127.0.0.1/::1，依赖audio/ingestion/indexing/answers/query-attachments及附件原依赖。不要求原图向量开关。独立原声模型profile、显式版本、维度、decoder revision及java_audio collection，与文字/图片集合不同；全装配后声明audio_vector_retrieval，构造零网络。
- AV-02：AudioEmbeddingModels小Interface：embed(byte[] canonicalWav)->immutable List<Double>，revision()/dimensions()/decoderRevision()。GeminiAudioEmbeddingModels按官方models.embedContent REST：固定v1beta/models/{model}:embedContent路径、x-goog-api-key header、单content.parts.inlineData{mimeType=audio/wav,data=完整canonical base64}、embedContentConfig{outputDimensionality,autoTruncate=false}。只完整16k mono s16le WAV、1..480000 samples（≤30秒），不发ASR/caption/URL/Files或拼多片段，不自动截断/重试/重定向。有限非零float32、固定2..3072维和严格embedding.values包络，未知/soft-tensor结果拒绝；模型路径/endpoint/version固定哈希排除密钥，加入decoder与PCM策略。旧共享HTTP默认Bearer行为保持，只新增固定Google入口，不做任意header网关。
- AV-03：认证精确GET/POST /v1/documents/{id}/audio-vector，无query/body。GET当前reader只读，不解码/调用模型；POST当前owner/editor、已indexed真实audio/旧当前文字target。默认120秒、全局2在途（1..8）、同doc一项，无后台任务/自动补建/重试。新旧资料同显式入口，当前profile完整合法receipt可幂等回读零解码/模型。
- AV-04：构建先冻结原publication/source SHA、全部已发布非空语音证据及base physicalIDs，真实解码原文件，不重复ASR。decoder revision必须与模型profile及保存AudioCompilation一致；按原服务器span时间映射精确sample边界，最后向上毫秒边界用实际PCM长度截止（不丢sample、不伪造时间）。每次新UUID vector generation。每entry绑定source/evidence/base physical/sample范围/PCM SHA与完整向量digest，text只使用PCM SHA，不用转录冒充原声向量。远程embed/init/upsert/整组完整verify在SQL事务外，父存活和collection lease复用；独立AudioVectorProtocol最多40MiB，原IndexProtocol/8MiB及ImageVectorProtocol原字节保持。所有分段都成功才短事务重验base/source/profile/完整映射/currentwriteACL并封存；失败/晚写只留未引用代次。
- AV-05：v18追加不可变audio_vector_publications及audio_vector_entries，完整多span manifest/segmentCount绑定一个原publication和独立profile/generation，旧表/active/publication/source/history不重写。提交须完整唯一evidence/base/vector映射、按原ordinal排序、合法samples/PCM SHA及全部entry/manifest digest，不能只封存成功前缀。备份/迁移/失败回滚沿原规则；回滚由原责任方配套恢复旧格式DB/JAR。
- AV-06：十字段metadata同图片合同：status(missing/available)、document_id、publication_id、source_revision_id、source_sha256、profile_fingerprint、model_revision、dimensions、vector_generation_id、manifest_sha256；missing最后两字段null，available的manifest代表完整全部已发布speech spans。无PCM、向量、转录、endpoint/key或私有配置泄漏。停止等待不保证撤回上游，必须显式刷新确认状态。
- AV-07：只AUDIO+存在实际prepared queryAudio+模块启用走原声dense。先冻结原完整selected/all scope，对其中全部audio publication核对当前完整receipt；缺/漂移明确audio_vector_required，不静默删资料或回退全库。QueryPreparation按同一实际解码与ASR流水保留所有音频分段PCM（含静音分段），不重复ASR，不筛第一/中/尾或截断；旧无音频参考/文字模式行为保持。原附件数/20MiB、问题和全部转录文字上限不放宽，PreparedQuery manifest绑定全部波形与source/decoder/sample/PCM SHA，旧无波形manifest保持原字节。
- AV-08：查询全部原波形逐路真实embed，独立图片/音频空间不混用，DENSE_ONLY COSINE先授权workspace/doc-vector generation过滤再top-K。每路全部candidate vectorIDs完整authority映射/hydrate成原PublishedAudioEvidence，后RRF最多64；坏尾/跨范围/重复冲突/错generation拒绝，不以COSINE原值冒充融合分数。模型/投影调用前后复验全部scope/receipts/profile，最终原trace事务再复验包括未引用资料。
- AV-09：原声向量只召回。排名/原问题/保存转录逐事实证明、typed audio citation及完整原音频SHA/真实时间来源继续，query音频不入库、不作证据。重启来源不调用原声模型，不能据向量或ASR文字声称识别说话者/非语音声学事实。默认关闭及无参考音频时旧文字、图片、附件、语音与视频行为回归保持。
- AV-10：前端0016在实际capability、indexed音频和当前编辑权限下独立读取/显式建立原声向量，说明全部分段与调用费用，reader只读。独立Session保持整理草稿，防重复，身份/资料/离页使迟到响应失效；停止后状态未知仅刷新，不自动构建或POST重试。两个代理精确无query/body POST独享180秒，GET普通期限，原认证/Origin/Host/JSON/上传预算不扩大。

必要正常链：同转录、不同实际波形的新旧已发布合成语音，多分段且尾段不同→缺当前receipt全范围拒绝/零原声embedding→显式完整建立→同profile重建零解码/模型→参考原音频真实解码/全部波形dense找回正确库内span→原转录事实证明→同source SHA原文件/真实时间Range→重启零模型来源；旧图片向量/语音/三媒体附件native另验。真实语义/ASR/provider/Milvus、网页及发布不由替身认证。

协议依据（2026-10-03只读核对）：[Gemini embedding指南](https://ai.google.dev/gemini-api/docs/embeddings)说明原音频MP3/WAV与内联；[REST API](https://ai.google.dev/api/embeddings)给出embedContent、embedContentConfig和embedding.values。本项目限定完整≤30秒canonical WAV及独立可配置Adapter，未配置/调用真实provider或读取凭据。
