# 执行计划

- backend build worker：批次选源、归档设置/schema43、直接测试。
- backend maintenance worker：影响/质量查询、版本绑定及增量提案、直接测试；不改schema。
- frontend worker：独立建设/待更新/质量页面、导入设置及回归，不改问答。
- root：精确代理、长请求期限、整链HTTP/浏览器验证、文档和交付。

先固定接口并记录旧行为，再实现；每条流程使用新合成资料。必要回归、格式和构建如实记录，旧失败保留。无云模型调用，无线上数据变更。工作树现有WIP不得回退。
