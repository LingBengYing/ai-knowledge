# 合同

- Java保留Python返回的已知安全错误码，未知/畸形错误仍泛化；区别任务超时、服务不可达、模型回调、动作/参数/最终结果协议失败，不改变成功响应和引用校验。
- Python安全日志仅run_id、枚举code和阶段/计数，不保存原问题、模型响应、思维链、工具正文或凭据。Java对应任务终态安全日志可关联run_id。
- 前端映射固定中文说明，显示任务编号/原因码供定位，不盲目建议重发，不自动重试。未知错误不直接呈现服务端自由文本。
- 不改schema/生产配置/服务；保留Spring分层与旧模型/检索行为。真实云质量复验另行执行，不能用合成测试冒称旧线上错误已修复。
