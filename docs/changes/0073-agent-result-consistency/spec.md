# 合同

- 有回答段落时必须先通过全部已读来源校验和维护建议文档校验；校验完成后统一 `refused=false`。仅修复冗余布尔标志，不补造、删减或改写任何段落/引用。
- 没有回答段落且 `refused=true` 时，可保留引用已读资料的维护建议，作为正常拒答结果交付。没有段落且 `refused=false` 仍判为缺少回答。
- 未检索、未阅读、空白段落、未知来源、未知建议文档与格式错误继续失败。Java 的规范化结果互斥检查、逐条来源及版本校验保持。
- Prompt 和 terminate 工具说明明确：部分回答也应为非拒答；拒答可带独立维护建议。
- HTTP 失败仍只输出一个固定 `error` 字段，但结果校验失败使用枚举化细码，经 Java 和 Web 展示具体原因。模型/资料正文和密钥不得成为诊断文本。
- 规范化不请求模型，不自动重试，不更改 SSE 流程；成功最终结果仍必须经 Java 校验及持久化。
