# 更新一份已有资料

后端0038和前端0027提供同资料原文件更新。实现与构建状态见[本轮记录](changes/0038-document-replacements/REVIEW.md)；自动化测试停止，页面由用户验收。

在资料详情的“更新原文件”区域点击“选择新原文件”。文件须与原资料属于同一类别：文档、图片、音频或视频。音频转录、普通视频沿该资料原来的处理通道，页面不更改通道。2026-11-03起独立声音与原视频音画通道已删除，这两类旧资料不能再更新原件（`can_upload=false`，上传返回409）。

上传新版本后，等待解析完成。点击“建立新版本索引”并确认模型与向量服务处理，资料沿后台任务处理。任务失败时可以按服务器允许的状态明确再次提交；不自动重试。

处理期间资料 ID、显示名称、目录、标签、权限与当前原件保持不变，当前已发布的内容仍可检索和回读。成功后服务器原子切换原件及索引，页面通过授权列表核对新 publication；问题和范围保留，但须重新检索或提问才能打开新来源。失败或取消保留旧发布。

新的文件内容不能使用旧图片/音频独立向量回执。新版本发布后，可在原详情向量面板明确建立新向量；系统不会在原件更新操作中自动调用这些额外模型。

写入超时或停止本地等待不代表服务器任务已取消。先点击“刷新新版本状态”确认，避免重复上传。已有整理草稿不必清空；更新按钮不会替你保存整理表单。
