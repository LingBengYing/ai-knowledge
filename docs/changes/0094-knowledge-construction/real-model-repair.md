## 修复合同

- 增量编译使用独立 `revise_wiki` 操作，OpenAI 兼容 HTTP 协议保持不变，仍为单次模型请求。
- 输入列明每个受影响章节的原编号、标题、正文及该章节允许使用的当前证据；required_evidence_groups按每份原资料提供证据别名组，每组至少引用一项。需要多份资料上下文的章节仍保留该上下文，多分片无需引用全部片段。
- 输出必须对每个目标章节返回且仅返回一次；未知、遗漏、重复编号或越界来源拒绝，不按具体标题、样本文本或相似度猜测去重。
- 服务端按原编号和原顺序替换受影响章节；未变章节的编号、正文和来源完整保留。资料版本检查、并发采纳检查与人工审阅保持。
- 不改变数据库 schema、公开 HTTP API、原件、旧资料、索引、前端或模型配置。
