# 行为合同

- 新导入资料自动完成解析→索引入队→发布；文件替换遵循同一正常链，旧有效版本保持至新版本发布。解析成功不得冒充可问。
- 自动续接由服务端持久化驱动，关闭/刷新浏览器和服务重启不丢失；一次解析成功只创建一次对应索引任务，失败不自动重复调用模型。
- 复用当前上传者身份、活动模型运行时、已有索引Service/Processor及来源校验；图片、音视频的索引类型按实际资料能力选择，不将视觉/音画资料错误送入文字索引。
- 旧parsed但未索引资料不静默回填；已提交的索引任务不重复。未配置必要模型时显示真实失败或待配置，不假成功。
- 原始资料只显示每份资料的处理/可问状态，移除解析/索引任务卡片、刷新任务按钮以及普通新导入的手动建立索引要求；完整任务进度/失败/显式重试集中现有任务菜单。
- 通过新合成资料验证上传→自动发布、离页/重启续接和重复防护；生产不修改旧资料，不借旧调用额度，沿当前授权批次单列实际请求。
