# Synthetic document fixtures

`synthetic-cedar.txt` is authored solely for this project's parser acceptance tests and contains no business data.
`synthetic-cedar.doc` is the real Microsoft Word binary document produced from that text using macOS `textutil -convert doc -inputencoding UTF-8`.
All other formats, including Outlook MSG, are generated by `DocumentFormatFixtures` from the same synthetic facts using Apache POI or explicit standard container/text structures. No external sample corpus or user file is included.

The DOC byte fixture is checked in so Linux CI does not need macOS or Office. Parsing it uses Apache Tika/POI, never `textutil` or an external conversion service.
