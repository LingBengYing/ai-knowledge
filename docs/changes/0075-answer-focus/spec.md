# 合同

- 查阅先区分判断、解释、比较、步骤、总结、找文件等用户任务，保留对象、明确限制与对话中的最新纠正；不得将相关旁支当作核心问题已解决。
- 每轮基于实际检索/阅读状态检查缺口，给出已读和未读候选编号。关键依据缺失时定向补查或阅读有帮助的候选；不强制阅读全部结果，不以固定搜索次数判定完整。
- 只有实际已读原文可引用。编号清单、历史、摘要、候选标题不作事实来源；原有来源身份/版本/取消/持久化校验不变。
- 最终首段直接回应核心问题或明确当前查阅未解决的缺口，随后给相关条件、依据或步骤；跨来源归纳同一问题，合并重复事实，不叙述已排除的不相关文件。仅明确找文件的任务以资料清单为主体。
- `statements` 的段落顺序由模型组织，多来源可支持同一段落；不增加新的输出格式字段或昂贵的独立总结阶段。内部source编号放evidence_ids，不写进正文；正式引用继续由Java生成。
- 每轮检查是执行事实提示和语义策略，不是假称能证明答案质量的硬门禁；`answered`仍只表示结果通过现有结构与来源校验。离线替身不能替代真实模型质量验收。
- Web0055只排版已有答案：安全段落/列表/强调，已验证编号打开原来源，按资料ID和版本折叠分组；不生成总结、不改保存正文、不把内部编号转换成正式引用。流式预览和正式引用发布时机保持。
