# 0071 模型返回内容与工具执行详情

负责人要求知识问答不再只显示阶段名称，要能看到工具调用细节，并明确要求显示其上游模型实际返回的思考内容。承接0070原生执行器与持久对话，不是展示本开发助手的隐藏推理，不增加用于生成解释的模型调用。

影响范围：Java AgentMessage/AgentToolProtocol/模型协议/AgentRunResult/KnowledgeAgentService、Python原生消息验证与同任务历史、会话result_json读取及前端进度视图。部署入口仍用现有任务/对话GET，无新增HTTP路由。旧阶段名称保留为旧记录回读，不伪造历史详情。

本轮覆盖0070中“完全不展示上游reasoning”的产品决定：仅上游明确返回的reasoning_content可成为对话内的可折叠展示内容，不写运行日志/异常/toString，不作为原件证据。生产配置、旧资料、模型调用余额及Git/部署边界保持。
