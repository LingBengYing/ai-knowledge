# Spec

1. 当前正常输入是单一产品操作问题以及同一授权视频的OCR产品标题和ASR操作。只有相同publication、revision、source SHA，且原时间区间实际相交时才可建立关联；不得通过文件名、手工标签、另一份PDF或查询附件建立产品身份。
2. 两份原文须实际摘录、精确匹配候选并保持原physical ID/上下文/字符区间。产品名严格匹配完整型号，动作完整包含时长、条件和结果；完整转录及OCR原上下文参加安全/否定/冲突判断。不把ASR描述称为视觉动作证明。
3. 在既有TextGrounding入口扩展typed知识证据验证，保留旧PDF和标量路径。不得拼造GroundingText页面、删主体或绕过拒答；同视频关联证明同时返回身份与动作原引用，综合及核验保留它们的依赖，不能只引用动作却丢失产品身份。
4. 复用既有KnowledgeReference/typed来源与trace。每条保留真实frame_interval或server_chunk，不伪造逐词/动作时间。文档、视频若都实际支持同一操作，可一并提供；不能为凑类型加入无关来源。
5. 仅处理当前产品使用正常路径。纯视觉推理、音画联合多事实、其他问句泛化仍沿原合同，不能用本分支替换。
6. 本地代码与无云回归已获授权。新视频的导入、ASR、索引与新问题必须另有具名模型预算；现有资料保持原状，当前0049批次已用完，累计18/20且halted。
