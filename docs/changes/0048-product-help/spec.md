# Spec：产品使用帮助首版

## 正常路径

1. 资料按现有目录、标签整理产品/型号/版本；在资料列表筛选并完整选择相关说明书和视频后进入帮助，也可直接全库查询。首版不新增产品主数据或自动猜测型号/版本，不把展示名称或标签当事实证据。
2. `POST /v1/product-help/search` 接受 `question`、可选 `document_ids`、`top_k`（每类默认5，1–10）、`rerank`（默认true）。问题与ID复用现有验证；省略范围表示完整授权全库，显式空数组保持空范围，所选不存在/越权/未发布资料不能静默丢弃或回退全库。
3. 复用当前已应用的managed文字模型和Milvus投影。文档和视频分别召回，再分别排序，避免文档数量淹没视频。仅查询嵌入及可选重排，不调用生成、ASR、VLM、索引写入或自动重建。已有HYBRID协议保持，不能把简单标题查找冒充向量召回。
4. 文档候选来自已发布原文/OCR。视频候选来自已发布真实ASR段、内嵌字幕cue、选中原帧OCR；caption、摘要和纯视觉描述不作原文结果。完整物理候选先经authority核验再按类型筛选，继续执行完整scope、配置和预算复验。
5. 响应保留真实document/revision、原filename、source SHA、原文内容及text SHA、相关性排序和类型化定位。HTTP使用平铺字段：文档page/start/end；视频start_ms/end_ms/time_precision，不适用字段为null。转录为服务器段起止时间，不是词级；字幕为原cue时间；OCR为原解码帧区间，不延长成整段操作。每类最多top_k，缺少合格候选时明确空结果，不以凑数量降低资格。排序分不是已校准置信度，未设通用相关性阈值，候选结果不等于事实证明或生成答案。
6. 来源使用现有按版本读取的原文件，前端核对document/revision/SHA后阅读或播放；不得拼造页码、时间、来源URL或绕过既有授权。媒体跳转失败如实提示，不伪称自动播放成功。
7. 前端独立`#/product-help`页面，问题/完整范围、加载/错误/空态、说明文档与使用视频两组结果。修改问题/范围/参数或离页使旧结果失效并释放媒体资源；取消不自动重试、不假定撤回上游费用。结果明确标记“原文检索片段，非生成答案”。

## 架构与边界

负责人追加要求：按OpenAI兼容协议设计模型接入，不按模型名称复制实现。ASR复用现有multipart AudioModels Adapter，更换星辰仅改外置model配置；协议实测不兼容才在Client边界归一化，不改Service/Repository。重排属于明确扩展合同，不冒充OpenAI标准。规则见Java开发规范AI01–AI04。

### 语音/字幕独立视频入库（2026-10-04追加）

实跑发现画面描述超时阻断了文字教程检索。负责人明确批准调整后继续同一批剩余18次请求，不重试该画面描述。新增显式 `RAG_VIDEO_TEXT_EVIDENCE_ONLY=true`（默认false），作为视频编译Module的小Interface选择；仍真实解码并封存完整选帧、原图SHA/PTS/时长、完整ASR与启用后的字幕/OCR，不装配或请求VLM描述。

仅新v4编译身份允许所有帧recall为空；旧v1–v3必须保留真实caption及原指纹。v28存储迁移允许三个recall字段同时为空，完整帧与EvidenceGroup数量不变；投影只计算实际caption、非空ASR、OCR和字幕。不填“无描述”等假证据，完全没有文字时不制造索引。

文字证据模式提供video_upload/video_index与product_help，不提供依赖VLM的video_answers，也不把该compiler装入旧视频查询附件链。默认视觉联合模式保持原合同。跨模态生成、纯视觉问答和附件能力不能由本条文字检索验收代替。

Controller处理HTTP，Service编排检索，Repository负责authority读取，DTO/Domain保持强类型，Config复用现有装配；不复制万能类、ServiceImpl壳或新权限体系。复用当前认证、ACL、active publication与原件校验。旧文字召回与旧各模态问答合同不变。

范围提示说明目录/标签选择只约束资料，未标注型号版本时不能保证全库结果属于同一产品。后续以统一产品metadata与混合事实证明增量解决，不在首版隐式宣称已具备。

## 验收方式与未验证边界

先记录现状：旧召回只支持页码文字候选，旧问答一次固定证据模式，不能在一个产品入口显示文档与视频片段。按当前停测指令，不执行自动化测试、格式/语法检查或独立审计，也不改变旧测试。可跳过全部测试构建、实际浏览本机页面。真实provider/Milvus检索与中文产品效果需要另行具名授权，未运行不记通过；不解除生产gate。
