# Review

实现前由三个现有代理只读复核已批准ROADMAP、0017与音频/前端实际Interface。独立输入准备→用户确认→旧问答可复用AudioCompilationService与AnswerSession；不以空问题/占位文字绕过附件合同，不要求尚无明确需求的现场录音，不牵入全部视觉/视频配置。

实现后限定复核按文件ownership进行，没有额外创建审查代理；Maven/Spotless及native均由root统一执行。pdf_ingestion已核查本切接口与接线，未提出阻断正常闭环的具体finding；结论限于本切默认开关/依赖、严格音频包络、共享接收器和对应既有附件边界，不视作生产或真实ASR质量认证。

BoundedMediaQueryServlet复用旧异步有界接收/等待生命周期，QueryAttachmentConfiguration与VoiceQuestionConfiguration各自提供独立handler/预算。旧QueryAttachmentServlet已删除，不保留兼容壳；旧附件TEXT/IMAGE业务分派及无visual时503 query_attachment_unavailable保持。QueryAttachmentHttpTest仅迁移构造夹具并补回其原visual=null的IMAGE拒绝分支，没有修改旧有效断言。最终交接必须记录删除项，避免部署时旧类残留或误恢复。

backend_originals限定追读AnswerProtocolServer、SourceFields与TextGrounding核对native首轮的精确quote合同：server候选返回完整evidence.text；SourceFields把句号作为字段分隔符，TextGrounding依据支持字段的field.text()及原CP offset返回GroundedQuote。因此上传原文“上海住宿上限为650元。”对应的合法精确摘录为“上海住宿上限为650元”。新IT原本含句号的期望未按此合同设定，仅新增独立POLICY_QUOTE，并在回答citation与GET来源两处使用同一精确assertEquals；不使用contains、不改server/证明policy/产品/旧测试。首轮失败日志保留，此项记为新测试合同期望修正，不算产品RED或已修产品缺陷。

本切有效业务RED只有冻结标签版上显式voice开关未产生voice_questions能力；新类型缺失、测试编译中间态与上述native错误期望均不冒充业务RED。相关121项GREEN已由root执行并归档；最终native复验、全量门禁、当前输入绑定与制品结果由root另行补充，本次限定复核不预报其结果。

输入准备只处理用户自给音频，返回完整LF连接文字与8项身份信息，不读取库、不创建资料/trace或把转录作为引用。确认后的文字仍经过旧AnswerCommand限制，完整scope在旧问答首次库模型调用前验证；原语音资料ASR失败与历史真实识别质量问题保持。native使用真实解码和loopback模型/Milvus协议夹具，零云请求；真实provider/中文ASR、浏览器用户验收和生产发布仍在本切本机证据之外。
