# 知识库一键启动

Git 中仅保存本目录的脚本和配置；启动还需完整离线包中的 `images.tar`。没有离线镜像时请使用相邻的 `../oneclick-online` 在线入口。

本包自带五个离线镜像，无需登录腾讯云，也不会询问仓库密码。

1. 解压到一个长期保存的目录，不要在压缩包内直接运行。
2. Mac 双击 **启动.command**；Linux 执行一次 **./start.sh**。
3. 等待显示“知识库已启动”，打开 https://knowledge.localhost:18443/ 。

后续仍双击同一个启动文件：镜像已导入就跳过，配置与资料自动复用。**停止.command / stop.sh** 停服务但不删资料；**状态.command / status.sh** 查看健康情况。

首次证书由本机生成，浏览器可能提示未受信任，需要本人确认或安装自己认可的证书。启动器不修改系统信任设置、不自动绕过浏览器提示。默认只绑定 127.0.0.1，保留本机免登录；不会把你的资料和配置公开到局域网或公网。

## 环境

Docker Engine 28+ 与 Compose v2（支持 up --wait）；镜像为 Linux AMD64。建议给 Docker 8 GB 内存和 20 GB 可用空间起步，资料增加时额外扩容；Apple Silicon 使用 AMD64 模拟，性能与原生 x86 不同。已有 Docker 权限的用户不需要额外 sudo。

默认端口18443；若冲突，在第一次启动前用 KB_PORT=18444 ./start.sh 指定一次即可。地址写入本目录 .env，以后无需重复输入。不要随意移动 .env、修改项目名或删除 Docker 数据卷。

## 模型

系统不自带任何模型密钥。打开网页“模型设置”，配置自己的生成、嵌入、重排模型一次即可；以后保存在本机数据卷。启动验收不调用真实模型。

默认图片/扫描PDF使用镜像内 Tesseract；云端 Paddle OCR 镜像已包含，但默认不启用，避免安装时要求云密钥或自动发送资料。当前包以已发布0094-r2/0062版本为准，未发布的多模态工作区修改不包含。

## 数据和故障

Docker 卷保存资料、数据库、索引和本机密钥；应用更新不能覆盖这些卷。备份须同时保存应用数据、Milvus 数据和 runtime 配置。停止脚本不使用 down -v。仅移除容器不会清空知识库。

容器布局：常驻的 `net` 容器（复用已固定的 api 镜像，只运行空等待循环）持有本机端口和共享回环网络；api、milvus、agent、web、gateway 都加入它。api 因内存不足自行退出并被 Docker 自动重启后，会重新加入同一网络，端口与内部连接不受影响。旧版本安装再次运行启动入口时，会先自动停止并移除旧容器（不删数据卷）再按新布局启动；若该步骤失败，先运行一次停止入口再启动即可。

如果显示启动失败，不代表已运行成功。查看本目录 logs/init.log、logs/status.log 和 Docker Desktop 服务日志。请勿反复重置或删除数据卷。

供应商仓库密码、生产数据和生产模型密钥均未打入此包。离线镜像身份记录在 images.lock，传输完整性由 images.sha256 校验。
