# Spec: 公开 Java 代码与文档

1. 独立 clone 在仓库根目录可构建；不依赖父目录或个人 Maven settings。
2. 保留管理鉴权、授权过滤、目录、标签、批量、审计与所有已完成回归用例。
3. 附加 TextParser PDF/TXT/Markdown 及原合成 PDF 定位测试，明确未接 HTTP/隔离 worker。
4. 不包含尚未实现的模型/检索/Authority 外壳；这些在本地的未完成测试继续保留，不能作为本仓库通过证据。
5. README、AI_CONTEXT、AGENTS、架构、API、路线图与安全说明提供准确的相对路径和状态，不包含私有主机或个人文件路径。
6. secret 从运行环境读取，示例为空；检查当前 Git 文件和可达历史，发现敏感内容失败关闭且日志不泄露命中值。
7. 全量测试、覆盖率、格式、Node 检查在此独立快照上重跑；历史报告不认证新源码。GitHub CI 配置本身不等于实际 CI 已通过。
8. 只正常创建/前进远端提交，不强推、不覆盖现有历史、不更改仓库可见性或凭据。
