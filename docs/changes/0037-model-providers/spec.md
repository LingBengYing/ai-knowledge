# 合同

每个文字角色保存 `provider`、模型和私有密钥。嵌入、重排支持 `siliconflow`；生成支持 `siliconflow`、`deepseek`。页面不输入 URL。硅基流动端点沿受信服务器配置；DeepSeek 使用官方地址，已有受信官方地址形式保留。

GET 原角色字段追加 `provider`；顶层全硅基流动为 `siliconflow`，混合为 `mixed`。PUT 角色可带 `provider`；省略时继承旧角色或首次默认硅基流动。更换服务商必须明确填写密钥，不跨服务商继承。旧私有 v1/v2 缺 provider 保持原硅基流动语义；新增 v3/v4 保存逐角色 provider，分别无/有索引锚点。

连接测试与实际运行使用该角色保存的服务商。保存、应用不自动测试或索引。仅更换生成服务商沿既有角色切换合同保留文字索引；索引锚点保存三个原端点，索引身份不随当前回答角色变动。已有来源继续按权限回读。
