1. 固定事件字段、旧记录兼容、思考同任务回传/展示分离及失败终态合同。
2. Java worker负责DTO/模型Adapter/服务端事件与相关测试；root负责Python协议字段、工件与集成。前端worker独立完成严格DTO/折叠渲染/轮询状态及测试。
3. 验证真实loopback请求携带原字段，工具开始/结束/失败状态、耗时、权威来源元数据；不读取或输出真实业务资料。
4. 最终新隔离实例完整问答、展开工具/思考、刷新会话/引用、窄屏及重启回读；模型返回fixture仅为合成公开短说明，不拿它认证真实供应商思考质量。
5. 更新REVIEW与verification，保留既有失败和未验范围；不额外展开权限或性能支线。
