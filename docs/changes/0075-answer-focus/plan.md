# 计划

1. Python worker负责agent-service主提示、每轮查阅状态及合成执行回放，先红后绿。
2. Web worker负责答案排版/引用分组/安全测试及Web0055工件，不改问答传输合同。
3. Root负责Java出站工具说明、Agent prompt版本、直接协议回归与跨模块审查。
4. 跑Python全套、相关Java协议/Service/SSE/会话回归、前端全套与本机合成浏览器检查；旧失败不删除或放宽。
5. 独立审查并记录实际结果。真实供应商语义、生产部署、全仓旧门禁本轮不认证。

复用现有Module Interface，无被替代的生产路由或兼容壳；prompt版本变化只影响新答案追踪，不更改模型/索引指纹或重建旧资料。
