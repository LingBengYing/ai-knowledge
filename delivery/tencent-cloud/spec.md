# 一键离线启动合同

用户授权完整一键启动，不反复输入仓库密码或命令。交付包含已上传五镜像的离线 archive、Compose、启动/停止/状态入口。启动包不含 TCR 或模型凭据，首次自动生成本机 JWT/Agent 凭据及 TLS 证书，重复启动保持数据和配置，默认仅本机访问并复用既有免登录流程。平台固定 Linux AMD64，Mac ARM 仅模拟运行验证，不宣称原生 ARM。模型在页面一次配置；Paddle OCR 是可选云服务，不默认外发资料。默认本地 Tesseract 路径可用。

验证空库初始化、健康检查、HTTPS 页面/会话/配置、Milvus 独立合成写入 Strong 读回、无模型 TXT 解析、停止重启数据保留、重复启动无重新加载镜像/无重新生成密钥。保留其他工作树和生产。不能通过暂停某个失败断言宣称全链成功。
