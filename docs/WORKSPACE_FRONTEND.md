# 新版独立前端：本机运行与能力边界

本入口用于独立 `ai-knowledge-web` 新版资料库、处理任务、资料详情、聊天及独立文字召回页面连接真实Java服务。它是显式本机开发模式，不是生产认证方案；普通 `run-dev.sh`、JWT默认和既有远端服务保持不变。

## 启动

需要JDK21+、Node.js22+，并已有 `target/rag-java-0.1.0-SNAPSHOT.jar`。将 `JAVA_HOME` 指向实际JDK21及以上的根目录，不把安装路径或私密配置提交仓库。当前自动化验证暂停；缺少JAR时由负责人按最新[AGENTS](../AGENTS.md)构建跳过全部测试的运行包，不执行历史 `verify` 或检查命令。

在Java仓库根目录启动后端：

```bash
bash run-workspace.sh
```

默认绑定 `127.0.0.1:18084`，使用本仓库独立 `.data/workspace` 数据目录。脚本复用 `run-dev.sh` 的不变JAR副本，不自动构建、灌入演示资料、读取 `.env`、接旧数据或调用模型。

在独立前端仓库根目录、另一终端启动页面：

```bash
npm start
```

没有第三方npm依赖，无需 `npm install` 或前端构建。打开 [新版前端](http://127.0.0.1:18085/)，使用字面 `127.0.0.1`，不要改成 `localhost`。Node本机同源代理默认连接Java18084；Java内置静态页面不是新版独立前端，资源不会自动互相复制。

若默认端口已有服务，使用新的专用目录和端口，不停止或复用其他服务：

```bash
RAG_DATA_DIRECTORY=./.data/workspace-local RAG_PORT=18086 bash run-workspace.sh
```

对应独立前端：

```bash
RAG_WEB_BACKEND_ORIGIN=http://127.0.0.1:18086 RAG_WEB_PORT=18085 npm start
```

开发代理只接受本机loopback，不能把本入口暴露公网或当作远端部署方案。

## 先走管理与文本解析

1. 页面使用本机开发身份 `owner`；workspace配置同时将其列为模型管理员。此身份只用于显式本机开发，不是JWT、SSO或生产账户。
2. 在资料库主动上传合成TXT、Markdown或支持的PDF，查看服务器持久解析任务；空库保持空状态，不自动创建演示行。
3. 等待解析完成，打开资料详情和原文件，整理显示名、目录或标签。整理不改变原文件身份，也不触发模型。
4. 解析完成只表示 `parsed`，不等于 `indexed` 或可问答。任务页沿现有授权资料和任务入口读取，不是新建的全库历史任务API。

workspace显式开启文本摄取、索引、答案及managed模型配置装配，但运行资格仍以实际服务能力和配置为准。没有应用模型时可以进行管理和文本解析，不使用假模型/假索引补齐召回或答案。workspace本身不自动开启全部图片、音频、视频或摘要资源。

## 配置模型后再索引与召回

在设置页保存逐角色服务商、模型ID、嵌入维度/版本等草稿；Milvus目标和凭据由后端可信配置提供。保存不等于应用，也不触发索引。模型协议、所需环境变量、密钥私有保存及既有操作步骤见[模型配置与召回](MODEL_SETUP_AND_RETRIEVAL.md)、[TEXT_ADAPTERS](TEXT_ADAPTERS.md)和[媒体装配](MANAGED_MEDIA_SETUP.md)。程序不自动加载 `.env`，密钥不写入本运行说明或源码。

手动连接测试、明确建立索引、召回与问答可能产生外部调用及费用，需要对应授权；本切没有新增模型调用额度，不执行这些真实模型操作。配置已明确应用后，由用户主动建立索引，再进入独立召回页核对实际片段及原来源，最后沿原有问答和来源合同使用。重排分不是答案置信概率，召回测试不调用生成、不创建答案引用。

独立文字召回的范围规则：

- 全库保留所有当前授权publication组成的完整scope，候选只读取真实text/OCR publication entry；纯视觉描述不冒充文字证据，远程阶段和返回前仍复验完整scope、ACL及配置。
- 全库非空但没有text/OCR时，返回原有 `empty/no_matches`、完整 `scope_count` 和空matches，不发送嵌入/检索/重排请求；真正空库仍为 `empty_scope`。
- 显式 `document_ids` 仍逐一验证；所选集合中无文字、未发布、不可用或越权资料不能被丢弃、回退全库或部分成功，显式空数组仍为 `empty_scope`。

本轮不新增聊天会话历史、全库任务列表或分段编辑接口；页面入口不能被当作服务端已提供这些能力。
